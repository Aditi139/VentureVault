# VentureVault – Entrepreneur Stories & Business Ideas

## About the Project

VentureVault is a Django-based web application that provides an online video directory showcasing entrepreneurial journeys, startup stories, and business ideas.

It helps students, aspiring entrepreneurs, and innovators learn from real-world business experiences through videos, entrepreneur profiles, and business insights.

## Features

- Browse entrepreneurial videos and startup stories.
- Explore entrepreneur profiles and company details.
- View entrepreneurial journey timelines.
- Search and filter videos by categories.
- Watch embedded YouTube videos.
- Save and bookmark favourite videos.
- Register, log in, and manage user profiles.
- Contact form for user inquiries.
- Admin panel to manage entrepreneurs, videos, categories, and other content.

## User Roles

- **Visitor:** Browse published videos, stories, and entrepreneur profiles.
- **Registered User:** Browse content, save videos, and manage their profile.
- **Admin:** Add, edit, delete, and publish platform content.
